# 10-Slot Midplane Carrier Board

## Specifications
* **Connectors:** Dual high-density 100-pin board-to-board receptacles per slot for Milk-V Mars CM modules.
* **Power Distribution:** Onboard synchronous buck regulators stepping down the centralized 12V DC system bus directly to 5V per blade.
* **Networking:** Integrated managed Gigabit Ethernet switch chip routing internal node traffic to a single external mesh uplink port.
