# HumanAIT Micro-Hub

A community-owned, non-profit, off-grid RISC-V compute hub engineered for ecological symbiosis, acoustic silence (0 dB), and sustainable infrastructure.

## System Architecture
* **Compute:** 10-blade cluster utilizing Milk-V Mars CM (StarFive JH7110 SoC).
* **Thermal Management:** Single-phase immersion cooling using bio-based synthetic ester (Oleon QLOE), linked via a refrigerant-to-liquid condenser to a subterranean copper Direct Expansion (DX) geothermal loop.
* **Power Resiliency:** Hybrid solar and LiFePO4 (5kWh) system featuring a direct 12V DC power distribution bus for maximum efficiency.
